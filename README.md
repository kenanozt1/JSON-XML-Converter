# JSON to XML and XML to JSON Converter

This project provides an application that allows users to convert data between JSON and XML formats. Users can convert JSON data to XML format or XML data to JSON format.

## Features

- **JSON to XML Conversion**: Convert JSON data into XML format.
- **XML to JSON Conversion**: Convert XML data into JSON format.
- **Copy Functionality**: Copy the converted data to the system clipboard.

## Technologies

- **Qt5/Qt6**: The application is developed using the Qt framework.
- **QML**: The user interface is developed using QML.
- **C++**: Backend operations are handled using C++.

## Installation

1. **Required Dependencies**:
   - Qt 5 or 6 must be installed.
   - Qt Creator IDE is recommended for development.

2. **Clone the Repository**:
   ```bash
   git clone https://github.com/kenanozt1/JSON-XML-Converter.git
   ```

3. **Install Project Dependencies**:
   You can open the project using Qt Creator, and the dependencies will be automatically installed.

4. **Running the Application**:
   Start the application by clicking the "Run" button in Qt Creator.

## Usage

1. **JSON to XML**:
   - Paste JSON data into the respective input field and click the "Send JSON" button.
   - The converted XML data will be displayed below.

2. **XML to JSON**:
   - Paste XML data into the respective input field and click the "Send XML" button.
   - The converted JSON data will be displayed below.

3. **Copy Functionality**:
   - To copy the converted data to the clipboard, use the "Copy" button.
